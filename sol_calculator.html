Metric Value Formula / condition

Formulas

N_rollout_gpu = ceil(N_robot / K_env)
M_rollout = ceil(N_rollout_gpu / G_max)
r_i = active rollout GPU ranks on node i
M_train = ceil(T_gpu / G_train_node)

step_interval = 1 / f
chunk_coverage = C / f
rtc_stride = C / 2
rtc_lookahead = rtc_stride / f
T_obs_pipeline_p99 + T_infer_p99 + T_action_pipeline_p99 + T_jitter_p99 <= rtc_lookahead

T_obs_pipeline_p99 = capture + preprocess + transport_lb + pack/unpack + ser/deser + queue
T_action_pipeline_p99 = transport_lb + pack/unpack + ser/deser + robot_enqueue
T_transport_lb = payload_bits / bandwidth + fixed_link_latency
H2D/D2H/PCIe terms can be lower-bounded by bytes / effective_bandwidth.
For K_env > 1, obs/infer/action p99 buckets must be measured under the chosen batching and fan-in/fan-out policy.

horizons_per_sec = N_robot * f / H
step_entries_per_sec = horizons_per_sec * H
chunk_entries_per_sec = horizons_per_sec * ceil(H / C)

step_replay_MBps = N_robot * f * S_step
chunk_replay_MBps = horizons_per_sec * ceil(H / C) * S_chunk
represented_primitive_steps_per_sec = N_robot * f
represented_steps_per_MB = represented_primitive_steps_per_sec / replay_MBps
per_full_rollout_gpu_steps_per_sec = K_env * f

direct_weight_bytes = N_rollout_gpu * W
node_scatter_bytes = M_rollout * W
B_cross = total aggregate effective bandwidth per direction
rollout_intra_recv_per_gpu_i = (r_i - 1) / r_i * W
rollout_intra_send_recv_per_gpu_i = 2 * rollout_intra_recv_per_gpu_i
rollout_intra_critical = max_i(rollout_intra_send_recv_per_gpu_i / B_rollout_intra)
optimal_cross_bytes = W
optimal_rollout_inter_bytes = (M_rollout - 1) * W
B_rollout_inter = total effective aggregate rollout inter-node collective bandwidth
T_rollout_intra = rollout_intra_critical
T_sync_direct = direct_weight_bytes * 8 / B_cross
T_sync_node_cross = node_scatter_bytes * 8 / B_cross
T_sync_node_no_pipeline = T_sync_node_cross + rollout_intra_critical
T_sync_node_pipeline_lb = max(T_sync_node_cross, rollout_intra_critical)
T_sync_optimal_cross = W * 8 / B_cross
T_sync_optimal_rollout_inter = optimal_rollout_inter_bytes * 8 / B_rollout_inter
T_sync_optimal_no_pipeline = T_sync_optimal_cross + T_sync_optimal_rollout_inter + rollout_intra_critical
T_sync_optimal_pipeline_lb = max(T_sync_optimal_cross, T_sync_optimal_rollout_inter, rollout_intra_critical)

T_update = K * H / f
deadline = L * T_update
fixed_rollout_time = T_rollout_inter + T_rollout_intra
required_B_cross_sum_ref = cross_comm_volume * 8 / (deadline - fixed_rollout_time)
T_sync_pipelined_lb = max(T_cross, T_rollout_inter, T_rollout_intra)
T_sync_sum_ref = T_cross + T_rollout_inter + T_rollout_intra
T_sync_selected = direct, node, or hierarchical sum reference for selected path
min_L_for_sync_ref = max(1, ceil(T_sync_selected / T_update))
replay_uplink_Gbps = replay_MBps * 8 / 1000

Caveats Not Modeled in v1

Robot resetReset after success/failure reduces effective robot utilization, but does not affect v1 SOL tables.
Availability / fault toleranceHA, failover, replay durability, scheduler resubmission, and degraded mode are out of scope.
Reward/eval overheadReward models, evaluators, human labels, and validation rollouts are not included.
Cold loggingStep-level audit video/log retention can be much larger than hot replay.
RTC data movementWire, PCIe, H2D, and D2H lower bounds are easy to derive, but pack/unpack and ser/deser stay inside measured pipeline buckets.
Algorithm semanticsLearning quality and on-policy constraints are represented only through the lag parameter L.
